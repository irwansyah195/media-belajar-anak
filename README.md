# 🦉 Taman Pintar — Platform Belajar Anak Usia Dini Ceria

**Taman Pintar** adalah aplikasi web interaktif, edukatif, dan ramah anak usia dini (PAUD/TK) yang dirancang untuk merangsang kognitif, motorik, bahasa, logika, dan kreativitas anak melalui petualangan belajar yang menyenangkan bersama maskot **Si Huki**.

---

## ✨ Fitur Utama

- 🪙 **Sistem Hadiah Koin Bintang Emas**: Anak mengumpulkan koin dari setiap jawaban benar dan bonus kemenangan permainan untuk membuka wahana dan hadiah baru.
- 🎡 **Taman Bermain Si Huki (Playground & Wahana Shop)**: Tempat anak menukarkan koin belajar untuk membeli dan memasang 8 wahana/dekorasi interaktif (Pohon Permen Karamel, Ayunan Pelangi, Perosotan Es Krim, Balon Udara, Komidi Putar Bintang, Rumah Pohon, Air Mancur Soda, Kastil Permen) yang dapat disentuh untuk memunculkan animasi dan suara ceria!
- 📖 **Buku Album Stiker Koleksi**: Mengoleksi 12 stiker lucu beranimasi dari kotak hadiah misteri (*Gift Box*) setiap menyelesaikan misi belajar.
- 🎙️ **Voice Narasi Interaktif (Text-to-Speech)**: Memandu anak dengan suara ramah berbahasa Indonesia di setiap tema, instruksi soal, dan apresiasi kemenangan.
- 🎠 **Komidi Putar Tema (Carousel)**: Navigasi tema belajar yang ceria, interaktif, dan mudah digeser baik di layar sentuh (*touch*) maupun desktop (*mouse*).
- 🎮 **2 Mode Bermain Utama**:
  - **Petualangan Sendiri (Mode Solo)**: Fokus pada eksplorasi mandiri, belajar bertahap, dan penguasaan materi secara bertahap.
  - **Main Berdua (Mode 2 Pemain / Duel Simultan)**: Bermain bersama teman atau orang tua dalam kompetisi sehat dan kooperatif di satu perangkat secara *real-time* tanpa perlu menunggu giliran.
- 🎨 **Desain Khusus Anak (Kid-Friendly UI/UX)**:
  - Tipografi ceria dan mudah dibaca (*Fredoka*, *Baloo 2*, *Nunito*).
  - Skema warna permen cerah (*Candy Palette*) dengan animasi tombol bergoyang (*jelly button*), efek partikel bintang (*star bursts*), dan hujan konfeti.
  - Kartu skor pemain berukuran besar, jelas, dan kontras dengan indikator pemimpin (*👑 Memimpin*).
  - Bebas tombol membingungkan dan sangat ramah sentuhan jari anak.
- 🔊 **Sistem Audio & Sound Effects Fidelitas Tinggi**:
  - **Efek Suara Tepuk Tangan Meriah (*Applause SFX*)**: Suara tepuk tangan penonton panjang dan meriah (~3.8 detik) setiap kali anak menyelesaikan permainan.
  - **Web Audio API Procedural Engine**: Melodi *fanfare* kemenangan emas, nada tuts piano Do-Re-Mi, denting koin, letup balon, seruling, gesekan balok, dan BGM chiptune ceria.

## 🕹️ Ragam Mini-Game Seru

### 🌟 Mode Petualangan Sendiri (Solo)
1. **🌻 Kebun Koleksi Ceria**: Mengumpulkan objek sesuai instruksi soal kuis tematik interaktif.
2. **📖 Cerita Petualangan**: Menjelajahi 5 pos petualangan bertahap dengan tantangan cerita bergambar.
3. **🌉 Jembatan Urut Logika**: Menyusun dan menempatkan balok kayu urutan angka/huruf/pola untuk menyeberangi sungai.
4. **✨ Cocokkan Ceria**: Menjodohkan gambar dan pasangan konsep yang tepat.
5. **🛒 Toko Ceria Si Huki**: Belanja interaktif dengan menarik (*drag & drop*) barang pesanan ke dalam keranjang rotan belanjaan.
6. **🧩 Puzzle Pasang Gambar**: Menyusun kepingan puzzle gambar tematik menjadi gambar utuh.
7. **🎹 Piano & Tangga Nada** *(Khusus Tema Musik)*: Keyboard piano virtual interaktif dengan tangga nada C-D-E-F-G-A-B-C.

### 👥 Mode Main Berdua (2 Pemain / Duel Simultan)
1. **🏎️ Balap Cepat**: Adu kecepatan menjawab soal kuis untuk melajukan mobil balap / roket menuju garis finis.
2. **🎈 Adu Cepat Letup Balon**: Duel simultan real-time di mana Pemain 1 dan Pemain 2 memiliki papan balon kiri-kanan simetris untuk adu cepat meletupkan balon sasaran yang tepat.
3. **🧠 Adu Cepat Memori**: Adu cepat mengingat dan mencocokkan pasangan kartu memori secara langsung di papan duel ganda tanpa antre giliran.
4. **🚂 Kereta Logika**: Melengkapi gerbong kereta api dengan memilih gerbong urutan yang tepat secara cepat.
5. **🔨 Tepuk Ceria (Whack-a-Target)**: Duel refleks dan fokus menepuk objek sasaran yang muncul dari sarang masing-masing pemain.
6. **🤝 Gotong Royong (Kerja Sama)**: Kedua pemain bekerja sama menjawab kuis di panel masing-masing untuk mengumpulkan target 10 bintang bersama ke dalam keranjang.

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur semantik modular dan antarmuka ramah perangkat mobile, tablet, maupun desktop.
- **CSS3 (Vanilla)**:
  - Tata letak responsif berbasis *Flexbox* dan *CSS Grid*.
  - Animasi halus (*Jelly Buttons*, *Floating Balloons*, *Pulse*, *Sparkle Bursts*, *Card Flip*, *Shaking Feedback*).
  - Desain modern *Glassmorphism* dan *Claymorphism* dengan kontras warna ramah anak.
- **JavaScript (Vanilla ES6+)**:
  - *State management* mandiri dan *touch/mouse event gesture handler*.
  - *Web Audio API* (Sintesis nada prosedural & pemutar file audio WAV fidelitas tinggi).
  - *Web Speech API* (`speechSynthesis`) untuk narasi suara pemandu bahasa Indonesia.
  - *Drag and Drop API* dengan *touch fallback* untuk perangkat layar sentuh.

## 🚀 Cara Menjalankan Aplikasi

Aplikasi ini bersifat **standalone (dapat langsung dijalankan di browser tanpa build step khusus)**:

1. **Unduh / Clone Repository**:
   ```bash
   git clone https://github.com/irwansyah195/media-belajar-anak.git
   ```
2. **Buka Aplikasi**:
   - Cukup buka file `index.html` langsung menggunakan web browser modern (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari, atau Opera).
   - Atau gunakan ekstensi seperti **Live Server** di VS Code atau server lokal (`http://localhost:8088/`).
3. **Tips Pengalaman Terbaik**:
   - Nyalakan speaker atau gunakan headphone untuk mendengar narasi Si Huki, musik latar, efek tepuk tangan, dan suara balon.
   - Sangat optimal digunakan pada layar sentuh (*tablet/touchscreen*) atau desktop.
